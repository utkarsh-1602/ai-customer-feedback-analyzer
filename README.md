# FeedbackIQ

> Turn customer feedback into product decisions.

FeedbackIQ is an AI-powered customer feedback analyzer that transforms unstructured customer feedback into actionable product insights.

Instead of manually reading hundreds of feedback entries, product teams can upload or paste feedback and quickly understand **what customers are saying, what problems are recurring, and what should be fixed first.**

## Live Demo

[View Live Demo](https://feedbackiq-ai-custom-z5uw.bolt.host/)

## Key Features

- AI-powered feedback analysis
- Sentiment analysis — Positive, Neutral, Negative
- Automatic theme and problem identification
- P0 / P1 / P2 prioritization
- Top customer problems
- AI-generated product insights
- Recommended product actions
- Suggested success metrics
- Feedback Explorer with search and filters
- CSV upload
- Paste feedback directly
- Demo dataset for instant analysis
- Local analysis fallback when AI is unavailable
- Responsive dashboard
